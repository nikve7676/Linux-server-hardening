# Evidence collection

This folder is reserved for **sanitized** screenshots or terminal transcripts of the actual Ubuntu and macOS checks. Four original screenshots were submitted and inspected; cropped images were prepared separately, but **no PNG files have been uploaded to this GitHub repository**.

See [Observed terminal results](observed-terminal-results.md) for the findings grounded in the supplied screenshots, and [Final Security Audit](../documentation/08-final-security-audit.md) for outstanding checks.

The submitted screenshots confirm effective SSH settings, UFW status, Fail2ban SSH jail status, sudo-group membership and parts of the listening-port list. Ubuntu's displayed date differs from macOS's displayed date; time synchronization still needs checking.

Only upload screenshots that show real outputs, with no credentials, private keys or sensitive infrastructure details. Do not create fake terminal results to fill this folder.
